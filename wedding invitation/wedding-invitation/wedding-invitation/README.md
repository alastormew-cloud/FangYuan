# Wedding Invitation Project

This project is a wedding invitation website designed to provide an elegant and interactive experience for guests. Below are the details of the project structure and its components.

## Project Structure

```
wedding-invitation
├── index.html
├── src
│   ├── css
│   │   └── styles.css
│   ├── js
│   │   ├── main.js
│   │   └── lightbox.js
│   ├── components
│   │   ├── header.html
│   │   ├── gallery.html
│   │   └── rsvp.html
│   └── data
│       └── guests.json
├── assets
│   ├── images
│   └── fonts
├── package.json
├── .gitignore
└── README.md
```

## Features

- **Elegant Design**: The website features a sophisticated color scheme and layout, ensuring a beautiful presentation of the wedding invitation.
- **Photo Gallery**: Guests can view a collection of images in a gallery format, with the ability to click on images to view them in a pop-up lightbox.
- **RSVP Section**: An interactive RSVP section allows guests to confirm their attendance easily.
- **Responsive Layout**: The website is designed to be responsive, ensuring a seamless experience on both desktop and mobile devices.

## Setup Instructions

1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Install the necessary dependencies using npm:
   ```
   npm install
   ```
4. Open `index.html` in your web browser to view the wedding invitation.

## Usage

- Guests can navigate through the website using the header links.
- Click on images in the gallery to view them in an elegant pop-up format.
- Use the RSVP section to submit attendance information.
